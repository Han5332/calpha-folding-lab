Join the training

This computer will train the Folding Lab's network together with the one that sent you this link. It needs to stay on the same network as that computer.

Windows

Download train.bat
  1. Keep the file if the browser asks, then double-click it.
  2. If Windows says it protected your PC, choose More info, then Run anyway.
  3. The first start installs Python packages (about 3 GB for PyTorch). Training has begun when the window says joined as … on cuda: NVIDIA … and starts counting units.

Close the window to stop. Double-click the file again to carry on. Keep the laptop plugged in and set it not to sleep.

Mac or Linux

With Python 3, numpy and PyTorch installed, paste this into a terminal:

mkdir -p ~/folding-lab-train && cd ~/folding-lab-train && curl -fsS -o contribute.py "{SERVER}/join/contribute.py?token={TOKEN}" && curl -fsS -o evonet.py "{SERVER}/join/evonet.py?token={TOKEN}" && python3 contribute.py --server {SERVER} --token {TOKEN} --chains 32

Progress, and whether the model is getting better, shows on the dashboard.
